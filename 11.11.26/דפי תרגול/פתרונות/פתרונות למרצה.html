פתרונות למרצה 01

לולאות ותנאי המשך

מקור: המצגות הצורך בלולאות בקוד, ייעוד ומבנה הלולאה while ואופן הפעולה שלה

תרגיל 1 זיהוי חזרתיות

מספיק משפט print אחד בגוף הלולאה. כדי להגיע עד 100 משנים רק את הגבול בתנאי.

n = 1
while n <= 5:
    print(n)
    n += 1

תרגיל 2 חיזוי פלט ומעקב

התנאי נבדק ארבע פעמים; הגוף מתבצע שלוש פעמים. בבדיקה האחרונה התנאי ״8 קטן מ־8״ הוא שקר.

n = 2
while n < 8:
    print(n)
    n += 2
print("end", n)

תרגיל 3 תיקון מבנה

מוסיפים נקודתיים ומזיחים את ההדפסה ואת העדכון. ההדפסה האחרונה נשארת מחוץ ללולאה.

n = 3
while n > 0:
    print(n)
    n -= 1
print("Done")

תרגיל 4 כתיבה עצמאית

הערך הראשון הוא 10 והאחרון הוא 0. לאחר העדכון האחרון המשתנה מכיל מינוס 2.

n = 10
while n >= 0:
    print(n)
    n -= 2
print("Go")

פתרונות למרצה 02

עצירת לולאות וקלט חוזר

מקור: המצגת הלולאה while והסכנה בלולאה אין סופית

תרגיל 1 לולאה שלא מתחילה

הגוף אינו מתבצע כלל, כי התנאי שקר כבר בבדיקה הראשונה. זו אינה לולאה אין סופית.

n = 0
while n > 0:
    print(n)
    n -= 1
print("Done")

תרגיל 2 עדכון בכיוון הלא נכון

המשתנה גדל ותנאי ההמשך נשאר אמת. מחליפים את ההגדלה בהקטנה. בסיום n שווה 0.

n = 3
while n > 0:
    print(n)
    n -= 1

תרגיל 3 סכום קלט עד סימן עצירה

חשוב לקרוא קלט חדש בכל סיבוב. עבור הדוגמה מתקבל 11; אם הקלט הראשון הוא מינוס 1 מתקבל 0.

total = 0
number = int(input())
while number != -1:
    total += number
    number = int(input())
print(total)

תרגיל 4 דילוג מעל ערך העצירה

רצף המספרים האי זוגיים לעולם אינו מגיע ל־10. התנאי החדש נכשל כאשר n מגיע ל־11.

n = 1
while n < 10:
    print(n)
    n += 2

פתרונות למרצה 03

מעבר על מחרוזות

מקור: המצגת הלולאה for ומעבר על מחרוזות

תרגיל 1 חיזוי פלט

מודפסות שלוש שורות. הרווח הוא תו בפני עצמו ולכן השורה האמצעית מכילה רווח בין הסוגריים.

for ch in "A B":
    print("[" + ch + "]")

תרגיל 2 קליטת מחרוזת

מספר הסיבובים שווה למספר התווים: שלושה, אחד ואפס, בהתאמה. גודל המחרוזת ידוע לאחר הקלט.

text = input()
for ch in text:
    print(ch)

תרגיל 3 השלמת שרשור

בכל סיבוב מצרפים את התו פעמיים. בקלט ריק התוצאה נשארת מחרוזת ריקה.

text = "dog"
result = ""
for ch in text:
    result += ch + ch
print(result)

תרגיל 4 אתגר היפוך סדר

מצרפים כל תו לפני התוצאה הקודמת. לאחר הסיבוב הראשון מתקבל r ולאחר השני or.

text = "robot"
result = ""
for ch in text:
    result = ch + result
print(result)

פתרונות למרצה 04

טווחים וסכומים

מקור: המצגות הלולאה for ומעבר על רצף מספרים ופעולות על רצף מספרים

תרגיל 1 קריאת טווחים

הגבול העליון אינו כלול. בטווח האחרון צעד ברירת המחדל חיובי ואינו מתקדם מ־5 לכיוון 2.

for values in (range(4), range(2, 9, 3),
               range(8, 1, -2), range(5, 2)):
    print(list(values))

תרגיל 2 גבול כולל

הגבול של range צריך להיות n + 1. כאשר n שווה 0 עדיין מתבצע סיבוב אחד.

n = int(input())
for number in range(n + 1):
    print(number)

תרגיל 3 סכום בקפיצות

המספרים הם 5, 8, 11, 14, 17, 20. הצובר מתחיל ב־0 והסכום הוא 75.

total = 0
for number in range(5, 21, 3):
    total += number
print(total)

תרגיל 4 אתגר מכפלה ועצרת

אתחול ב־0 היה מאפס כל מכפלה. עבור 0 הלולאה ריקה והצובר נשאר 1; עבור 5 מתקבל 120.

n = int(input())
product = 1
for number in range(1, n + 1):
    product *= number
print(product)

פתרונות למרצה 05

שילוב תנאים בלולאות

מקור: המצגת הלולאה for ושילוב תנאים

תרגיל 1 ספירת סיבובים והדפסות

הלולאה והתנאי מתבצעים שבע פעמים. ההדפסה מתבצעת פעמיים, עבור 3 ועבור 6.

for n in range(1, 8):
    if n % 3 == 0:
        print(n)

תרגיל 2 סכומים נפרדים

סכום הזוגיים הוא 30 וסכום האי זוגיים הוא 25.

even_total = 0
odd_total = 0
for n in range(1, 11):
    if n % 2 == 0:
        even_total += n
    else:
        odd_total += n
print(even_total, odd_total)

תרגיל 3 ספירת תו

התוצאות הן 3, 0 ו־0 בהתאמה. ההשוואה מבחינה בין אות קטנה לאות גדולה.

text = input()
count = 0
for ch in text:
    if ch == "a":
        count += 1
print(count)

תרגיל 4 אתגר סינון תנועות

בקלט שאין בו תנועות קטנות התוצאה ריקה. התנאי בודק חברות ברצף התנועות.

text = input()
result = ""
for ch in text:
    if ch in "aeiou":
        result += ch
print(result)

פתרונות למרצה 06

רשימות ופעולות בסיסיות

מקור: המצגת מבוא לרשימות

תרגיל 1 אינדקס ואורך

האינדקס של האיבר האחרון הוא 2. אורך הרשימה הוא 3, כי האינדקסים מתחילים ב־0.

items = ["bread", "milk", "eggs"]
print(items[0])
print(items[2])
print(len(items))

תרגיל 2 רשימת קניות

ההכנסה משנה את האינדקס של milk ל־2. הרשימה הסופית מכילה ארבעה איברים.

items = ["bread", "milk", "eggs"]
items.append("apple")
items.insert(1, "rice")
items[2] = "water"
del items[items.index("eggs")]
print(items)
print(len(items))

תרגיל 3 איתור ומיון

האינדקס של 85 במקור הוא 0 וברשימה הממוינת הוא 2. הפונקציה sorted יוצרת רשימה חדשה ומשאירה את המקור ללא שינוי.

scores = [85, 70, 95, 60]
print(scores.index(85))
ordered = sorted(scores)
print(ordered)
print(ordered.index(85))

תרגיל 4 אתגר ניהול רשימה

שומרים את הערך לפני המחיקה כי del אינה מחזירה אותו. האיבר שנמחק הוא Coraline.

books = []
books.append("Dune")
books.append("Coraline")
books.append("Holes")
removed = books[1]
del books[1]
books = sorted(books)
print(removed)
print(books)

פתרונות למרצה 07

רשימות מתקדמות

מקור: המצגת נושאים מתקדמים ברשימות

תרגיל 1 סינון בעזרת לולאה

הרשימה החדשה מכילה cat ו־banana. הוספה לרשימת תוצאה נפרדת אינה משנה את המקור.

words = ["cat", "dog", "banana", "kiwi"]
selected = []
for word in words:
    if "a" in word:
        selected.append(word)
print(selected)

תרגיל 2 הבניית רשימה

הביטוי מחשב ריבוע והתנאי בוחר מספרים זוגיים. הטווח מסתיים לפני 9.

squares = [n * n for n in range(9) if n % 2 == 0]
print(squares)

תרגיל 3 העתקה לעומת שם נוסף

המשתנים a ו־b מצביעים לאותה רשימה. המשתנה c מצביע להעתק נפרד; כאן האיברים הם מספרים.

a = [1, 2]
b = a
c = a.copy()
b.append(3)
c[0] = 9
print(a)
print(c)

תרגיל 4 אתגר רשימות מקוננות

במטריצה בוחרים שורה ואז עמודה. בקובייה בוחרים שכבה, שורה ואז עמודה.

grid = [[1, 2, 3], [4, 5, 6]]
cube = [[[1, 2], [3, 4]], [[5, 6], [7, 8]]]
print(grid[1][2])
grid[0][1] = 20
print(grid[0])
print(cube[1][1][1])

פתרונות למרצה 08

פונקציות וערכי החזרה

מקור: המצגת מבוא לפונקציות, בנייה, קריאה, החזרה וערך חסר

תרגיל 1 הדפסה אינה החזרה

הפונקציה מדפיסה 6 אך אין בה return, ולכן מוחזר None ונשמר במשתנה result.

def show_double(n):
    print(n * 2)

result = show_double(3)
print(result)

תרגיל 2 פונקציה שאפשר לשלב בחישוב

הערך המוחזר זמין להמשך חישוב אצל הקוד שקרא לפונקציה.

def multiply(a, b):
    return a * b

result = multiply(4, 5) + 3
print(result)

תרגיל 3 זיהוי ערך חסר

המספר 0 הוא ערך תקין ואינו None. לכן בדיקת אמת כללית אינה מספיקה כאן.

def first_or_none(values):
    if len(values) == 0:
        return None
    return values[0]

print(first_or_none([]) is None)
print(first_or_none([0, 7]) is None)
print(first_or_none([0, 7]))

תרגיל 4 אתגר פונקציה עם לולאה

הפונקציה מחזירה 3, 0 ו־0 בהתאמה. הצובר מאותחל בכל קריאה מחדש.

def count_a(text):
    count = 0
    for ch in text:
        if ch == "a":
            count += 1
    return count

print(count_a("banana"), count_a("CAT"), count_a(""))

פתרונות למרצה 09

רקורסיה

מקור: המצגת מבוא לפונקציות, רקורסיה ותנאי עצירה

תרגיל 3 ספירה רקורסיבית

מדפיסים לפני הקריאה הבאה. כאשר n שווה 0 יוצאים ללא קריאה נוספת, ולכן התהליך מסתיים.

def countdown(n):
    print(n)
    if n == 0:
        return
    countdown(n - 1)

countdown(3)

תרגיל 4 אתגר תנאי בסיס

בכל קריאה n קטן ב־1 ולכן יגיע ל־0. סכום המספרים מ־1 עד 4 הוא 10.

def sum_to(n):
    if n == 0:
        return 0
    return n + sum_to(n - 1)

print(sum_to(0))
print(sum_to(4))

פתרונות למרצה 10

פרמטרים ותחומי משתנים

מקור: המצגת נושאים מתקדמים בפונקציות

תרגיל 1 פרמטרים וארגומנטים

הפרמטרים הם name, price, student. הארגומנטים הם Dana, הערך True והמספר 30, המועברים בהתאמה.

def ticket(name, price=40, student=False):
    print(name, price, student)

ticket("Dana", student=True, price=30)

תרגיל 2 ברירות מחדל וסדר העברה

ארגומנט מיקומי רגיל אינו יכול להופיע אחרי ארגומנט לפי שם. אפשר לתקן באמצעות age=22.

def describe(name, age=18, city="Haifa"):
    print(name, age, city)

describe("Noa")
describe(city="Eilat", name="Noa", age=22)
describe(name="Noa", age=22, city="Eilat")

תרגיל 3 משתנה מקומי

ההשמה בפונקציה יוצרת משתנה מקומי. המשתנה החיצוני נשאר 10.

x = 10
def change():
    x = 99
    print(x)

change()
print(x)

תרגיל 4 אתגר עדכון ערך חיצוני

בקוד המקורי ההשמה הופכת את count למקומי ולכן הקריאה לפני ההשמה נכשלת. בגרסה השנייה הקורא שומר את הערך המוחזר.

count = 0
def add_one():
    global count
    count += 1
add_one()
add_one()
print(count)

def increment(value):
    return value + 1
count = increment(increment(0))
print(count)
