מטרה: לזהות חזרתיות, להבין הזחה ולעקוב אחר המשתנה שמשנה את תנאי הלולאה.

הנחיות: חזו פלט לפני הרצה. כתבו קוד בקובץ נפרד והסבירו את הבחירות שלכם. הניחו קלט תקין בתחום שצוין.

תרגיל 1 זיהוי חזרתיות

כתבו לולאת while שמדפיסה את המספרים מ־1 עד 5, כולל. הסבירו מה צריך לשנות כדי להגיע עד 100, וכמה שורות print נדרשות בגוף הלולאה.

תרגיל 2 חיזוי פלט ומעקב

לפני הרצה, רשמו את הפלט ואת ערך המשתנה n בסיום. כמה פעמים נבדק התנאי וכמה פעמים מתבצע גוף הלולאה? כתבו גם את בדיקת התנאי האחרונה.

n = 2
while n < 8:
    print(n)
    n += 2
print("end", n)

תרגיל 3 תיקון מבנה

תקנו את הקוד כך שידפיס את המספרים מ־3 עד 1, ואחריהם פעם אחת את המילה Done. הסבירו אילו שורות נמצאות בתוך הלולאה.

תרגיל 4 כתיבה עצמאית
