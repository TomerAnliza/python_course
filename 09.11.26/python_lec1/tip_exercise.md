# מיני תרגיל — מחלקים את הטיפ

הארוחה נגמרה, החשבון הגיע, ועכשיו כולם מסתכלים זה על זה: כמה טיפ משאיר כל אחד?
כתבו תכנית שעונה על השאלה.

## מה התכנית עושה

1. שואלת מה סכום החשבון.
2. שואלת כמה אחוזי טיפ משאירים.
3. שואלת כמה סועדים ישבו ליד השולחן.
4. מדפיסה את סך הטיפ, ואת חלקו של כל סועד בטיפ.

## דוגמת ריצה

כתבו את הקוד בקובץ חדש בשם `tip.py`, והריצו:

```bash
python tip.py
```

כך נראית ריצה תקינה:

```text
What is the bill? 480
What is the tip percentage? 12
How many diners? 4
Total tip: 57.6
Tip per diner: 14.4
```

## שתי נקודות לפני שמתחילים

- הפונקציה `input` מחזירה תמיד `str`. לפני כל חישוב צריך להמיר את הקלט למספר.
- מספר הסועדים הוא תמיד שלם, אבל חשבון יכול להיות `480.50`. בחרו לכל קלט את ההמרה המתאימה לו: `int` או `float`.

## למי שסיים

1. הדפיסו גם כמה כל סועד משלם בסך הכול: חלקו בחשבון ועוד חלקו בטיפ.
2. הריצו עם חשבון של `100`, טיפ של `10` ושלושה סועדים. מה מודפס, ולמה? עגלו את התוצאה לשתי ספרות אחרי הנקודה בעזרת `round`.
3. הריצו פעם אחת עם `0` סועדים, ופעם אחת עם `three` במקום מספר. איזו שגיאה מתקבלת בכל ריצה, ובאיזו שורה בקוד היא נזרקת?
