הורד למחשב את ההקלטות מהקישורים שאצרף, באמצעות הכלי yt-dlp ועוגיות הסשן של Google Chrome.

הקישורים: [הדבק כאן את קישורי ההקלטות]
תיקיית היעד: [הכנס נתיב, או השתמש בתיקיית recordings בתוך תיקיית העבודה]

ראשית זהה את מערכת ההפעלה ובדוק אם הכלי מותקן:

yt-dlp --version

אם הכלי חסר, בחר רק את פקודת ההתקנה המתאימה לסביבה. במק עם מנהל החבילות Homebrew:

brew install yt-dlp

במערכת Windows עם מנהל החבילות winget:

winget install --source winget --id yt-dlp.yt-dlp

לחלופין, בסביבת Python מתאימה שמאפשרת התקנת חבילות:

python3 -m pip install -U "yt-dlp[default]"

לאחר ההתקנה בדוק שוב את הגרסה. אם נדרש עדכון, השתמש במנגנון של שיטת ההתקנה שנבחרה; להתקנה באמצעות Homebrew:

brew upgrade yt-dlp

פתח כל קישור בכרום בפרופיל שבו אני מחובר לשירות, והמתן עד שנגן ההקלטה זמין. אם נדרשת התחברות או סיסמה שאין לך, בקש ממני להשלים אותה בדפדפן. אל תפתח פרופיל חדש וריק.

צור קובץ בשם links.txt ובו הקישורים שסיפקתי, קישור אחד בכל שורה. הורד באמצעות:

yt-dlp --cookies-from-browser chrome --batch-file "links.txt" -P "recordings" -o "%(title)s [%(id)s].%(ext)s" --no-overwrites --abort-on-unavailable-fragments

החלף את תיקיית היעד לפי בקשתי. אם יש כמה פרופילים בכרום, זהה את הפרופיל שבו פתחת את ההקלטות והחלף את ערך העוגיות בהתאם; לדוגמה, רק אם זהו שם הפרופיל הנכון:

--cookies-from-browser "chrome:Profile 1"

קרא את העוגיות ישירות מהדפדפן ואל תציג את תוכנן. אם חילוץ העוגיות נכשל, דווח על השגיאה ועל הצעד הדרוש להמשך; אל תניח שההורדה הצליחה. אם נדרש מיזוג של וידאו ואודיו, בדוק שהכלי ffmpeg מותקן והתקן אותו בשיטה המתאימה למערכת אם חסר.

בסיום בדוק את קוד היציאה, את קיום הקבצים ואת האפשרות לנגן אותם. דווח אילו הקלטות ירדו, היכן נשמרו ואילו נכשלו. ציין במפורש אם לא הצלחת לבדוק ניגון.
